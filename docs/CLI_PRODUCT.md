# Roppo CLI 产品边界

更新：2026-11-26。CLI 是个人 Roppo 的终端入口，与网页共享同一账号、个人对话和后台执行。借鉴 Claude Code 的终端体验，功能取舍由 Roppo 的个人助手定位决定。

## 仓库依据

- `src/chat.ts` 的 `space()` 维护账号当前个人对话，项目会话不进入个人空间列表；`selectTerminalSession()` 同步网页选中的个人对话。
- `web/chat/main.tsx` 通过个人空间创建对话，并对 Router、Worker、内部收件人和详情展示作区分。网页仍保留团队和执行诊断视图。
- `src/chat.ts` 的 Worker 分派、回传和文件交付保留执行归属。CLI 改变展示层，不删除这些协作能力和权限边界。

## 面向用户的体验

1. 从任意目录启动，都继续自己的个人对话。`roppo`、`roppo -c`、`roppo -p` 默认一致；附件和本地设置仍从当前目录解析。
2. 主界面只有用户与 Router 的公开消息。内部 Worker 回复、分派消息和任务完成日志不插入默认聊天记录。
3. 欢迎页展示身份、模型和常用入口，不展示 Worker 数量或项目分类。任务协作保留在后台；Ctrl+O 和显式诊断命令按需展开。
4. 展示用户可理解的进展、真实流式回复、已交付文件、待授权操作和待回答问题。文件结果不能因为内部消息被隐藏而丢失。
5. 授权菜单说明动作和范围，提供允许、拒绝；用户无需先选择 Worker 或抄写任务 ID。复杂结构化问题目前仍可在同一网页对话中完成。
6. 退出终端不停止后台工作；显式中断、停止操作继续走宿主取消机制。

## 借鉴的交互与动效

- 简洁欢迎区、清楚的输入边界、Markdown/代码排版、键盘优先菜单、多行粘贴、文件补全、可恢复草稿。
- 发送和命令加载时立即显示活动状态；执行时显示轻量动画与实际耗时；回复按后端提供的内容更新，不人为添加逐字延迟或虚构完成百分比。
- 只重绘变化的终端行。输入位置稳定，主动翻阅历史后不抢回滚动位置，空会话不滚动。
- `/config motion=reduced` 停止周期动画，仍保留真实状态变化和消息更新；`motion=full` 恢复动画。
- 菜单移动、确认、返回即时反馈；授权动作只在明确选择后执行。

## 兼容与范围

显式 `--cwd`、旧项目会话、`/tasks`、`/diff` 和底层请求命令继续兼容，移出默认产品动线。`/help advanced` 可查看诊断命令。机器可读输出保留任务字段，便于既有脚本使用。

不以照搬 Claude Code 命令数量作为验收标准。记忆、文件、计划任务和外部工具应使用 Roppo 已有服务；终端入口必须有真实后端能力，不能只显示无效菜单。本轮未新增记忆编辑、计划任务管理、插件安装等终端专用界面；这些能力仍可通过对话或已有网页入口使用。
