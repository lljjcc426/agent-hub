# 页签切换动效

## 实现

共用无依赖的 Web Animations 控制器，接入 React 工作台和独立配置页。

- 下划线或分段滑块：220 毫秒，按实际选中项位置移动和缩放。
- 页签内容：180 毫秒，随切换方向轻移 8 像素并淡入。
- 工作台页面：200 毫秒，轻移 6 像素并淡入。
- 选择立即生效；不增加请求，不重建业务组件，不改变草稿、焦点和任务状态。
- 快速反向切换和原生页面的数据刷新均从当前动画位置接续。
- 后台刷新、浏览器标题变化和流式内容更新不重播选中动画。
- 开启减少动态效果或页面进入后台时取消动画，直接显示最终状态。
- 尺寸变化重新对齐选中条；父级切换时避免对子页签内容重复播放。

## 覆盖

任务、行为规则、设置及配置维护、Agent 执行视图、Agent 设置、Router/Worker 运行记录、指令窗口、接入分类、插件市场、自动化详情、会话资源标签、浏览器网页标签；侧栏切换页面也使用统一过渡。
